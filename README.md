## Parte 1. Diseño y responsividad en Web
En este parte del proyecto se realiza el diseño tanto con HTML como con CSS de una página de tienda de videojuegos
Utilizando herramientas aprendidas como los modelos de cajas, tipos de displays y media queries para ajustar el tamaño
## Parte 2. Funcionalidad de compra
Con la misma página web, se plantea generar un sistema completo de ventas, permitiendo realizar diversas acciones
tanto para el consumidor como para el administrador de este sistema. Dichas actividades que se plantean realizar son:
* Comprar con o sin registro de cliente
* Mostrar artículos disponibles
* Al hacer una compra, el inventario disminuye
* Generar una factura PDF
* Pagar con PayPal

El administrador tiene acceso al CRUD (Create, Read, Update, Delete) de los productos del inventario.
